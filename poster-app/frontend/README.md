# frontend/

ここに `poster-app-v6.html` を **`index.html` にリネームして**配置してください。

- Netlifyのドラッグ＆ドロップデプロイは、フォルダ直下の `index.html` をトップページとして配信するため、ファイル名は `index.html` に統一します
- 配置したらこのREADMEの下のチェックを済ませてコミットしてください

配置後の確認:

1. ファイル内のGAS WebアプリURL（`/exec` で終わるURL）が現在のデプロイと一致しているか
2. スプレッドシートID等の環境情報が `../CLAUDE.md` の記載と一致しているか
